# МТ-7 · Үнэлгээний апп 💾

«Мэдээлэл хадгалах төхөөрөмж» хичээлийн ажлын хуудасны **найзын үнэлгээ**, **бататгах 4 асуулт**, багшийн **шууд самбар**.

| Хэсэг | Хаяг | Хэн ашиглах |
|---|---|---|
| Нүүр | `…/unelgee/` | Сурагч |
| Найзаа үнэлэх (28 оноо) | `…/unelgee/#peer` | Сурагч |
| Бататгах асуулт (4 оноо) | `…/unelgee/#quiz` | Сурагч |
| Багшийн самбар | `…/unelgee/#board` | Багш (проектор) |

`SCRIPT_URL` тохируулаагүй үед апп **туршилтын горим**-оор ажиллана: хариу зөвхөн тухайн утсанд хадгалагдана. Ангид ашиглахаас өмнө доорх 2 алхмыг хийнэ үү.

---

## Алхам 1. Google Sheets сервер үүсгэх (5 минут)

1. [sheets.new](https://sheets.new) руу орж шинэ хүснэгт үүсгэнэ. Нэрийг нь жишээ нь «МТ-7 Үнэлгээ» гэж өгнө.
2. Цэснээс **Extensions → Apps Script** дээр дарна.
3. Нээгдсэн цонхны бүх кодыг устгаад, энэ repository-ийн `apps-script/Code.gs` файлын кодыг бүхэлд нь хуулж тавина. 💾 **Save** дарна.
4. Баруун дээд буланд **Deploy → New deployment** дарна.
   - ⚙️ дүрс дээр дарж **Web app** сонгоно.
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
   - **Deploy** дарна. Google бүртгэлээрээ зөвшөөрөл өгнө (*Advanced → Go to … (unsafe) → Allow*: энэ бол таны өөрийн скрипт).
5. Гарч ирсэн **Web app URL**-ийг хуулна (`https://script.google.com/macros/s/…/exec` хэлбэртэй).

## Алхам 2. Аппд холбох

1. GitHub дээр `config.js` файлыг нээгээд ✏️ (Edit) дарна.
2. `SCRIPT_URL: ""` гэсэн хашилтын дунд хуулсан URL-ээ тавина:
   ```js
   SCRIPT_URL: "https://script.google.com/macros/s/XXXX/exec",
   ```
3. `CLASSES`-д ангиудаа бичнэ. Хүсвэл `BOARD_PIN: "1234"` гэж самбарын нууц код тавина.
4. **Commit changes** дарна. 1–2 минутын дараа апп хүснэгттэйгээ холбогдож, «Туршилтын горим» гэсэн шошго алга болно.

## GitHub Pages асаах

Repository → **Settings → Pages → Build and deployment**:
- **Source:** Deploy from a branch
- **Branch:** `main` / `(root)` → **Save**

## Хичээл дээр

- Апп-ын хаягийг QR код болгож слайд дээр тавина. Сурагчид утсаараа уншуулаад нэвтэрнэ.
- Проектор дээр `#board` хуудсыг нээнэ: сурагчид илгээх бүрт 5 секундын дотор шинэчлэгдэнэ.
- Бүх хариу Google Sheets-ийн **«Найзын үнэлгээ»**, **«Бататгах асуулт»** хуудсанд хадгалагдана.

**Оноог хэрхэн тооцох вэ:** нэг сурагчийг хэд хэдэн удаа үнэлсэн бол **сүүлийн** үнэлгээ, бататгах асуултад хэд хэдэн удаа хариулсан бол **анхны** оролдлого самбарт тооцогдоно. Нэрийг үсгийн том, жижгийг ялгалгүйгээр харьцуулна.

## Код засварласан бол

Apps Script-ийн кодыг өөрчилсөн бол **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** дарна. Ингэхэд URL өөрчлөгдөхгүй.
